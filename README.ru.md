# NahNoMinimap

[English](README.md) | **Русский**

Плагин для Paper, который ограничивает поддерживаемые моды на карты и миникарты.

## Возможности

- Ограничение поддерживаемых миникарт и карт мира.
- Уведомления администрации при обнаружении каналов поддерживаемых модов.
- Настройка ограничений для всего сервера или отдельных миров.
- Разрешения для обхода ограничений и получения уведомлений.
- Настройка сообщений о запрете через языковые файлы.
- Интеграция сообщений с поддерживаемыми плагинами ресурспаков.

## Поддерживаемые моды

| Мод | Поддержка |
| --- | --- |
| Xaero's Minimap | Ограничения и уведомления |
| Xaero's World Map | Ограничения и уведомления |
| Diorama | Ограничения |
| JourneyMap | Ограничения и уведомления |
| VoxelMap | Ограничения и уведомления |
| Conflux Map | Ограничение радара и уведомления; полное отключение с версии 0.1.15 |
| WMap | Уведомления |
| Surveyor Framework | Уведомления |

Возможности ограничения зависят от мода и его версии. Изменённые клиенты
могут игнорировать ограничения сервера. Обнаруженный канал указывает на
возможное наличие мода, но не обязательно доказывает, что игрок использует его.

## Требования

- Paper или совместимый форк
- Minecraft 26.3
- PacketEvents

Сейчас поддерживается только Minecraft 26.3. Поддержка более старых версий
не планируется, но может быть добавлена по запросу.
